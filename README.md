# Examining Multilevel Interconnectedness in Entrepreneurial Ecosystems: Within-Ecosystem and Between-Ecosystem Dynamics

Supplementary material for the PhD thesis "Examining Multilevel Interconnectedness in Entrepreneurial Ecosystems: Within-Ecosystem and Between-Ecosystem Dynamics" by Pallavpreet Kaur, Deakin University, 2026.

The thesis is made up of three essays. This repository holds the analysis files supporting Essays 1 and 2.

## Contents

| File | Relates to | Description |
|---|---|---|
| `SLR_Essay1_Process_Derivation_041126 (3).xlsx` | Essay 1 | Systematic literature review workbook showing how the processes and propositions in the conceptual framework were derived. |
| `Thesis_Analysis_Scripts_021126.pdf` | Essay 2 | R scripts used for the fuzzy-set Qualitative Comparative Analysis (fsQCA). |
| `fsQCA_R_Output_Chapter3_Essay2.pdf` | Essay 2 (Chapter 3) | R output from the fsQCA, testing whether the combinations of conditions named in the Essay 1 propositions produce the expected outcomes. |

## Essays
- **Essay 1:** Develops a conceptual framework of entrepreneurial ecosystem dynamics, drawing on Developmental Systems Theory (DST) and Coleman's framework. It is built from a systematic literature review and sets out testable propositions.
- **Essay 2:** Tests the Essay 1 propositions using fsQCA.
- **Essay 3:** Completes the thesis's examination of within-ecosystem and between-ecosystem dynamics.
